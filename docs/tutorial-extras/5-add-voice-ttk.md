# Thêm giọng nói TTK

Thêm giọng nói TTK của bạn vào chương trình để sử dụng

## Hướng dẫn

Vào menu **Cài đặt** <i class="fa-solid fa-arrow-right"></i> **Thêm giọng**

- Chọn ngôn ngữ cần thêm
- Chọn giới tính
- Đặt tên cho giọng nói
- Chọn file `.mp3`

:::note[Chú ý]
- Chỉ chọn file có kích thước nhỏ hơn `20 MB`
:::

![AddVoice](/img/extra/add-voice.png)

#### *Hình 1 - Cửa sổ thêm giọng*


- Vào Tab **Quản lý giọng** đã thêm để có thể *thêm, xóa, sửa*


:::tip
- Chọn file có giọng rõ ràng, không bị nhiễu
- Giọng được thêm vào sẽ ở cuối các giọng mặc định của chương trình
:::
