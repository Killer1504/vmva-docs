# Nối video/audio

Dùng để nối <i class="fa-solid fa-link"></i> *video/audio* lại với nhau thành 1 file duy nhất

## Hướng dẫn

Vào menu **Tiện ích** <i class="fa-solid fa-arrow-right"></i> **Nối file**

- Thêm các file cần thiết để nối với nhau
- Ở bảng danh sách file, sẽ hiển thị thông tin của các file vừa thêm
    - Tên
    - Codec
    - Kích thước
    - Thời lượng
- Bạn có thể sắp xếp lại thứ tự các file bằng cách click vào ⋮ và sắp xếp theo ý muốn
- Click **Bắt đầu**, đặt tên để lưu và chọn **OK**

![Concat](/img/extra/concat-ui.png)

#### *Hình 1 - Cửa sổ nối file*

:::tip
- Chọn sử dụng GPU nếu bạn nối video
- Các file cùng thông số sẽ giảm thời gian nối
- Chỉ nối được video với video, audio với audio
:::
