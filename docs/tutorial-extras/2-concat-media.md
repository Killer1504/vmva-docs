# Nối video/audio

Dùng để nối <i class="fa-solid fa-link"></i> video/audio lại với nhau

## I. Hướng dẫn

Vào menu **Tiện ích** <i class="fa-solid fa-arrow-right"></i> **Nối file**

- Thêm các file cần thiết để nối với nhau
- Ở bảng danh sách file, sẽ hiển thị thông tin của các file vừa add
- Bạn có thể sắp xếp lại thứ tự các file
- Click **Bắt đầu**, đặt tên để lưu và chọn **OK**

![Concat](/img/extra/concat-ui.png)

#### *Hình 1 - Cửa sổ nối file*

:::tip
- Chọn sử dụng GPU nếu bạn nối video
- Các file cùng thông số sẽ giảm thời gian nối
:::
