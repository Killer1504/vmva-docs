# Chuyển đổi sang file `.mp3`

Dùng để chuyển đổi file *video, audio* <i class="fa-solid fa-arrow-right"></i> sang file `.mp3`

## Hướng dẫn

Vào menu **Tiện ích** <i class="fa-solid fa-arrow-right"></i> **Chuyển đổi sang file .mp3**

- Chọn file cần chuyển đổi
- Chọn các tùy chọn nâng cao
    - Bitrate
    - Channel
    - Sample rate
    - Âm lượng
- Click **Bắt đầu**, đặt tên để lưu và chọn **OK**

![ConvertMp3](/img/extra/convert-mp3.png)

#### *Hình 1 - Cửa sổ chuyển đổi sang .mp3*

:::tip
- Khi thêm file, thông tin file sẽ hiển thị ngay cạnh button **Bắt đầu**
:::
