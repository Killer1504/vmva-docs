# Đăng nhập

Sử dụng **user, password** và **computer id** máy để đăng nhập

- Lấy computer id của máy gửi cho admin computer id để đăng ký khoản
- Đăng nhập
- P/s: mỗi tài khoản chỉ dùng được ở trên 1 máy tính



## I. Đăng nhập

Dùng **user** và **password** để đăng nhập

- B0 - Nếu chưa có tài khoản, click vào **Đăng ký tài khoản**, lấy computer id để đăng kí
- B1 - Nhập user, password
- B2 - Nhấn **Đăng nhập**

![ComputerId](/img/authen/login.png)

#### *Hình 1 - Giao diện đăng nhập app*


## II. Đăng ký

Là mã đại diện cho thiết bị 
- B1 - Click vào đăng ký tài khoản, một cửa sổ hiện như hình 2
- B2 -  Bạn hãy copy mã này và gửi cho admin
