# Giới thiệu

Hãy khám phá các bước cơ bản để làm việc với app VMVA.

## 1. Đăng nhập

Tạo tài khoản và sử dụng

- Bạn cần có tài khoản để sử dụng app
- Mỗi tài khoản chỉ đăng nhập được trên 1 máy tính

## 2. Tạo project

Tạo project để làm việc

- B1. Đặt tên project, chọn nơi lưu và chọn template tương ứng

- B2. Làm theo hướng dẫn trong từng template, sau đó export video hoặc audio

:::tip
Có thể run nhiều project cùng 1 lúc
:::

## 3. Cài đặt thư viện

Các thư viện cần thiết để chạy project full tính năng

- Thư viện generate lyric <i class="fa-solid fa-arrow-right"></i> speech 2 text
- Thư viện voice clone <i class="fa-solid fa-arrow-right"></i> clone giọng nói
- Thư viện tách vocal <i class="fa-solid fa-arrow-right"></i> tách vocal và instrument
- Thêm api key của ChatGPT (model gpt-4.1-mini)
- Chọn server tạo audio

## 4. Các tính năng chính

 1. Thuyết minh phim
 2. Review truyện tranh, truyện chữ
 3. Viết lại kịch bản theo phong cách tùy chỉnh
 4. Tạo giọng nói từ text, có thể clone theo giọng bất kỳ
 5. Làm lyric cho video
 6. Thêm mặt nạ, zoom cho video mobile (9:16) <i class="fa-solid fa-arrow-right"></i> thành video 16:9

:::tip
Bạn có thể mở đồng thời nhiều `instance` để làm việc với nhiều project cùng 1 lúc
:::
