# Download

## Tải xuống

- Download app tại **[google driver](https://drive.google.com/file/d/14QYIjAuzyCh3ls5siPG7YETivA9Ni5AY/view?usp=sharing)**
- App chỉ *khả dụng* trên máy tính dùng hệ điều hành *Windows*

## Hướng dẫn cài đặt

- Click vào file `.msi` vừa tải về
- Chọn `Yes` nếu hệ điều hành có cảnh báo về author của file
- Click `Next` và tiếp tục
- Finish
