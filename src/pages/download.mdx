# Tải xuống và cài đặt

## 1. Tải xuống

- Download file cài đặt tại **[google driver](https://drive.google.com/file/d/14QYIjAuzyCh3ls5siPG7YETivA9Ni5AY/view?usp=sharing)**


## 2. Hướng dẫn cài đặt
- Giải nén file `.zip` vừ tải về
    - Dùng winrar hoặc 7z để giải nén
- Click đúp vào file `VMVA.msi`
- Chọn `Yes` nếu hệ điều hành có cảnh báo về author của file
- Click `Next` và tiếp tục
- Finish
- App sẽ tự khởi động khi cài đặt xong, bạn cần làm theo các hướng dẫn trong tài liệu để làm việc

:::note
- App chỉ *khả dụng* trên máy tính dùng hệ điều hành *Windows* (Từ Windows 7)
:::
